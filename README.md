# AI Motion Lottery Machine

Figma의 로또 추첨기 디자인을 바탕으로 만든 인터랙티브 모션 실험입니다.

## Files

- `index.html` — 브라우저에서 실행되는 Canvas 기반 애니메이션
- `lottery-machine.json` — 6초 반복형 Lottie JSON 애니메이션

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Motion behavior

- 약한 하단 송풍
- 유리통 내부 난류장
- 유리통 벽 충돌
- 공끼리는 통과
