# AI UI Motion Lab

AI와 UI 사이에서 빠르게 실험한 모션 프로토타입을 모아두는 작은 모션 실험실입니다. Lottie JSON과 브라우저 미리보기를 함께 정리합니다.

## Motions

| Motion | Description | Preview | Lottie JSON |
|---|---|---|---|
| 로또 머신 Lottie | 로또 추첨기 구조와 공 움직임을 실험한 모션 | `motions/lotto-machine/index.html` | `motions/lotto-machine/lottery-machine.json` |
| 물방울형 폭죽 Lottie | 중심에서 핑크 톤 물방울 파편이 퍼지는 폭죽 모션 | `motions/droplet-firework/index.html` | `motions/droplet-firework/droplet-firework.json` |

## Run Locally

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 열면 전체 모션 목록을 볼 수 있습니다.
